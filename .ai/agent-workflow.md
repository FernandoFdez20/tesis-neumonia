# Agent Workflow

Antes de modificar código:

1. Leer `.ai/instructions.md`.
2. Leer el archivo específico según la tarea:
   - UI: `.ai/ui-rules.md`
   - Backend: `.ai/backend-rules.md`
   - ML: `.ai/ml-rules.md`
3. Revisar la arquitectura actual del proyecto.
4. Proponer cambios mínimos.
5. Implementar sin romper estructura existente.
6. Explicar brevemente:
   - qué se cambió
   - por qué
   - qué archivos fueron modificados

No hacer:
- reescrituras masivas sin pedirlo
- cambiar stack
- inventar endpoints
- meter estilos inline innecesarios
- crear componentes duplicados
- eliminar código funcional sin justificar
