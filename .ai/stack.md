## Machine Learning
- Deep Learning aplicado a radiografías de tórax
- Modelo entrenado para detectar neumonía y clasificar gravedad
- Entrada principal: imagen de radiografía de tórax
- Salida esperada:
  - diagnóstico presuntivo
  - probabilidad/confianza
  - nivel de gravedad
  - prioridad dinámica si existen múltiples casos
